# Security and privacy

This repository and its GitHub Pages site are public. Do not commit secrets, tokens, credentials, email addresses, private conversation exports, precise home addresses, local filesystem paths, or unrelated personal information.

The dashboard has no login, form submission, administrative interface, analytics, cookies, or backend. Repository modification and deployment settings remain protected by GitHub account permissions and the repository owner's GitHub security settings.

If sensitive data is committed accidentally, stop deployment, remove the data from the full Git history, rotate any exposed credential, and document the remediation without repeating the secret.
